# ER YAPI - Agent Project Rules

## Tipografi ve Font Size Kuralları (MANDATORY)

1. **`text-xs` (12px) ve daha küçük font boyutları kesinlikle YASAKTIR:**
   - Projenin hiçbir yerinde `text-xs`, `text-[10px]`, `text-[11px]`, `text-[12px]` vb. küçük font sınıfları kullanılamaz.
   - Rozetler (badges), etiketler, marka adları, ürün kodları, tarih bilgileri, arama sonuç sayaçları, alt metinler ve buton yazıları EN AZ `text-sm` (14px) veya `text-base` (16px) font boyutunda olmak zorundadır.
